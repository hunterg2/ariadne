    Settings

    Tightens the sidebar rows and the gaps between things. Useful once you have a lot of folders open at once.

    Puts the number of images beside each folder name. It has to look inside every folder to work this out, so it costs a moment on a slow drive.

    An edited copy gets tagged #edited, so you can find them later and tell them from the originals. The tag lives in your library, not in the file.

    Off by default: sorting the sidebar leaves the contents of groups in the order you arranged them. Each group also has its own sort control if you only want one of them sorted.

    Dragging while a sort is on keeps the order you can see and switches back to Manual, so the move sticks. Turn this off if you would rather it refused.

    Dragging under a sort keeps the order you can see and switches back to Manual order, so your arrangement sticks.

    Warns before saving in a format that will lose something, such as flattening transparency or dropping metadata.

    Only for workflows that don't record the line themselves. Shown as a guess, never as recorded data.

    Kept in settings.json in plain text, on this machine only. Anyone who can read that file can read the key.

    Adds the checkpoint filename as a tag, without its extension.

    Adds each LoRA filename as a tag.

    Ratings and tags live only in organizer.db, and nothing on disk carries them. A copy is saved to backups/ every time the app starts; this is the portable version.
